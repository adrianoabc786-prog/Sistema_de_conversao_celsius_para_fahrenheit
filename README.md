# Sistema_de_convers-o_celsius_para_-fahrenheit
🌡️ Conversor de Temperatura com Funções
Este projeto é um utilitário simples em Python que converte temperaturas de Celsius para Fahrenheit. O diferencial deste código é a aplicação de funções (def) e retorno de valores (return), conceitos centrais na Engenharia de Software para a criação de sistemas modulares.

🚀 O que este código faz?
O programa solicita uma temperatura em graus Celsius ao usuário, processa a conversão através de uma função matemática dedicada e exibe o resultado formatado no console.

🧠 Conceitos de Engenharia Aplicados
Neste script, foquei em praticar:

Modularização: Uso de def para isolar a lógica de conversão da lógica de interface (entrada/saída).

Encapsulamento Simples: A fórmula matemática está "escondida" dentro da função, facilitando futuras manutenções.

Reutilização: A função converter_celsius_para_fahrenheit poderia ser copiada para qualquer outro sistema sem necessidade de alterações.

🛠️ Como executar
Certifique-se de ter o Python instalado.

Salve o arquivo (sugestão de nome: conversor_termico.py).

Execute o comando:

Bash
python conversor_termico.py
